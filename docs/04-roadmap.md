# 04 — Дорожная карта (roadmap)

Поэтапно, от «видим друг друга» до «удобно как настоящий телефон». Каждая фаза
самодостаточна — после неё уже есть рабочий результат, можно остановиться или
продолжить.

Оценки — для одного разработчика в свободное время (выходные/вечера). Это
ориентир, не обязательство.

---

## Фаза 0 — Подготовка ⏱️ ~1 вечер

Настройка окружения и аккаунтов. Кода почти нет.

- [ ] Создать аккаунт LiveKit Cloud, создать проект, получить `API key`,
      `API secret`, `wss://`-URL → см. [07-livekit-setup.md](07-livekit-setup.md)
- [ ] Завести аккаунт Vercel (можно через GitHub)
- [ ] `npx create-next-app` — каркас проекта (TypeScript + Tailwind)
- [ ] Положить `.env.local` с ключами, убедиться что он в `.gitignore`
- [ ] Инициализировать git-репозиторий, первый коммит

**Результат:** пустой проект запускается локально, ключи на месте.

---

## Фаза 1 — MVP: видеозвонок работает ⏱️ ~1–2 выходных

Цель: двое заходят в одну комнату и видят/слышат друг друга. Без уведомлений —
договариваемся голосом «я зашёл».

- [ ] Эндпоинт `/api/token`: принимает имя участника + семейный код, возвращает
      JWT (используя `livekit-server-sdk`)
- [ ] Главная страница: одна большая кнопка **«Позвонить»**
- [ ] По нажатию: запрос токена → подключение к комнате `family` через
      `@livekit/components-react` (`<LiveKitRoom>` + `<VideoConference>`)
- [ ] Базовые элементы управления: выключить/включить микрофон, камеру, выйти
      (есть в готовых компонентах LiveKit)
- [ ] Запрос доступа к камере/микрофону по нажатию кнопки (не на загрузке)
- [ ] Деплой на Vercel, проверка с HTTPS → см. [08-deployment.md](08-deployment.md)
- [ ] Тест: я с компьютера + телефон → реальный звонок

**Результат:** ✅ можно созваниваться уже сейчас (по договорённости о времени).

---

## Фаза 2 — UX для родителей ⏱️ ~1–2 выходных

Цель: чтобы родитель справился сам, без подсказок. Это «сердце» проекта.

- [ ] Крупный, контрастный, простой интерфейс (одна кнопка во весь экран) →
      см. [05-ux-for-parents.md](05-ux-for-parents.md)
- [ ] Понятные состояния: «соединяюсь…», «жду, когда ответят», «нет камеры/
      доступа», «нет интернета»
- [ ] Дружелюбные подсказки при отказе в доступе к камере (как разрешить)
- [ ] Экран настройки устройства `/setup?code=...` — одноразовая привязка,
      запоминание имени участника
- [ ] PWA: manifest + иконка, чтобы добавлялось на домашний экран как приложение
- [ ] Адаптив под телефон / планшет / десктоп, проверка на реальных устройствах
- [ ] Звук и видимая индикация, когда собеседник подключился

**Результат:** ✅ родитель открывает иконку и звонит сам.

---

## Фаза 3 — Настоящий «звонок» (уведомления) ⏱️ ~1–2 выходных

Цель: можно позвонить, не договариваясь заранее — второй человек узнаёт о звонке.
Самостоятельная тема — детали и выбор подхода в
[06-notifications-and-ringing.md](06-notifications-and-ringing.md).

- [ ] Presence: показывать, кто сейчас в сети (Supabase Realtime / Ably)
- [ ] Сигнал «звоню» + входящий звонок со звуком и кнопкой «Ответить»
      (когда приложение открыто)
- [ ] Надёжное оповещение, когда приложение закрыто — выбрать одно:
  - [ ] Telegram-бот шлёт «Артём звонит, нажми ссылку» (рекомендуется: просто и
        надёжно для родителей), **или**
  - [ ] Web Push (true «звонок» с экрана блокировки, требует разрешения и PWA)

**Результат:** ✅ полноценный видеотелефон — звонишь когда угодно.

---

## Фаза 4 — Полировка и надёжность ⏱️ по желанию

- [ ] Поведение при плохой сети (переподключение, индикатор качества)
- [ ] Простые настройки: выбор камеры/микрофона, если их несколько
- [ ] Аналитика ошибок (например, Sentry free) — чтобы знать, если что-то падает
- [ ] Резервный сценарий: кнопка «позвонить обычным звонком», если видео не идёт
- [ ] Лёгкое визуальное оформление (семейное фото, тёплые цвета)

---

## Идеи на будущее (вне текущих рамок)

Не делаем сейчас, но архитектура позволяет добавить:

- Групповые звонки (3+ участника) — LiveKit умеет, поменяется в основном UX.
- Запись разговоров / автоответчик («оставить видеосообщение, если не ответили»).
- Текстовый чат и обмен фото.
- Демонстрация экрана (помочь родителю разобраться с чем-то на его экране).
- Несколько «контактов»/комнат, если семья расширится.

---

## Рекомендуемый порядок

**0 → 1 → 2 → 3.** После Фазы 1 уже можно реально пользоваться (с
договорённостью). Фаза 2 делает это пригодным для родителей. Фаза 3 превращает в
«настоящий телефон». Не беритесь за Фазу 3, пока 1–2 не работают стабильно на
устройствах родителей.
