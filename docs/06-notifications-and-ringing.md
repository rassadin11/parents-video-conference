# 06 — Уведомления и «звонок»

## Суть проблемы

LiveKit (как и любой видеосервис) соединяет тех, кто **уже зашёл** в комнату. Он
не умеет «звонить» человеку, который сейчас сайт не открыл. А родитель не будет
держать сайт открытым весь день.

Значит, нужен **отдельный механизм оповещения**: «тебе звонят — зайди».
Это не часть видеозвонка, а сигнал поверх него.

> Это единственная по-настоящему нетривиальная часть проекта. Поэтому она вынесена
> в отдельный документ и в отдельную фазу ([04-roadmap.md](04-roadmap.md), Фаза 3).
> В MVP мы её обходим договорённостью голосом.

## Три уровня решения

От простого к надёжному. Можно идти по нарастающей.

### Уровень 0 — Договорённость (MVP, Фаза 1)
Просто звоним/пишем в обычном мессенджере «я зашёл, заходи» → оба нажимаем
кнопку. **Ноль кода.** Подходит, чтобы запустить видео и убедиться, что всё
работает. Минус: нужно заранее списаться.

### Уровень 1 — Presence + звонок внутри приложения (Фаза 3)
Оба клиента держат лёгкое постоянное соединение с realtime-сервисом
(Supabase Realtime / Ably — бесплатные тарифы). Тогда:

- видно, **кто в сети** («Артём сейчас доступен»);
- при нажатии «Позвонить» второму прилетает событие → у него **звенит звонок**
  со звуком и кнопкой «Ответить».

**Плюсы:** настоящий «входящий звонок».
**Минусы:** работает, только пока у второго приложение **открыто** (вкладка
активна). На телефоне вкладка в фоне может «засыпать» — звонок не придёт.

Поэтому Уровень 1 хорош как дополнение, но не как единственный способ.

### Уровень 2 — Оповещение, когда приложение закрыто (Фаза 3, главное)
Чтобы «разбудить» человека с закрытым приложением, нужен push снаружи. Два
реалистичных варианта:

#### Вариант A — Telegram-бот (рекомендуется для родителей)
При нажатии «Позвонить» наш сервер через Telegram Bot API шлёт родителю
сообщение: **«📞 Артём звонит! Нажми, чтобы ответить: <ссылка>»**.

- ✅ Родители уже пользуются Telegram — ничего нового ставить не нужно.
- ✅ Уведомления Telegram надёжно доходят даже при заблокированном телефоне.
- ✅ Просто реализовать: бот + знать `chat_id` каждого родителя.
- ⚠️ Это не «звонок с рингтоном на весь экран», а громкое уведомление со
  ссылкой. На практике для семьи этого достаточно.

#### Вариант B — Web Push (настоящий «звонок»)
PWA + service worker + подписка на push (библиотека `web-push` + VAPID-ключи).
Сервер шлёт push, устройство показывает уведомление даже при закрытом
приложении.

- ✅ Максимально похоже на «звонок телефона».
- ⚠️ Нужно разрешение на уведомления (барьер для родителей).
- ⚠️ На iOS push работает только для PWA, добавленной на домашний экран
  (Safari 16.4+). Чуть капризнее в настройке.
- ⚠️ Сложнее: хранить подписки, обновлять при их протухании.

## Рекомендация

```
Фаза 1 (MVP):     Уровень 0  — договорённость голосом
Фаза 3, шаг 1:    Уровень 1  — presence + входящий звонок (когда открыто)
Фаза 3, шаг 2:    Уровень 2A — Telegram-бот как надёжный «будильник»
Позже (по вкусу): Уровень 2B — Web Push, если хочется «как настоящий звонок»
```

**Почему Telegram, а не сразу Web Push:** для нетехнических родителей Telegram —
путь наименьшего сопротивления и самый надёжный канал доставки. Web Push красивее,
но капризнее и требует возни с разрешениями. Начать стоит с Telegram, а Web Push
добавить позже как улучшение, если захочется.

## Что понадобится для каждого варианта

| Вариант | Доп. сервисы | Доп. секреты | Сложность |
|---|---|---|---|
| Presence (Ур.1) | Supabase / Ably (free) | ключ realtime-сервиса | средняя |
| Telegram (Ур.2A) | Telegram-бот (@BotFather) | `TELEGRAM_BOT_TOKEN`, `chat_id` родителей | низкая |
| Web Push (Ур.2B) | — (свой service worker) | VAPID public/private ключи | высокая |

## Эскиз сценария «настоящий звонок» (Telegram)

1. Родитель открывает приложение, нажимает «Позвонить Артёму».
2. Фронт заходит в комнату `family` и параллельно дёргает наш эндпоинт
   `/api/ring` (имя того, кому звоним).
3. `/api/ring` шлёт Артёму в Telegram: «📞 Мама звонит! Ответить: <ссылка>».
4. Артём жмёт ссылку → открывается приложение → попадает в ту же комнату → видео.

Симметрично в обратную сторону. `chat_id` обоих родителей и мой — заранее
зашиты в конфиг/переменные окружения (известны на этапе настройки).
