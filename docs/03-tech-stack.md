# 03 — Технологический стек

> Перед установкой свериться с актуальными версиями: пакеты LiveKit и Next.js
> обновляются часто. Команды ниже — ориентир, не догма.

## Рекомендуемый стек

| Слой | Технология | Зачем |
|---|---|---|
| Фреймворк | **Next.js (App Router) + TypeScript** | Фронтенд и серверный `/api/token` в одном проекте, бесплатный деплой на Vercel |
| UI | **React 19** | Стандарт, отлично сочетается с компонентами LiveKit |
| Стили | **Tailwind CSS** | Быстрая адаптивная вёрстка, крупные кнопки/тач-зоны |
| Видео (клиент) | **`livekit-client`**, **`@livekit/components-react`**, **`@livekit/components-styles`** | Готовые React-компоненты комнаты: видео-сетка, кнопки микрофона/камеры/выхода |
| Видео (сервер) | **`livekit-server-sdk`** | Генерация JWT-токенов доступа в `/api/token` |
| Медиа-инфраструктура | **LiveKit Cloud** | Сам SFU/медиасервер. Бесплатный тариф |
| Хостинг | **Vercel** | Бесплатно, авто-HTTPS, serverless-функции для токенов |
| PWA | **manifest + service worker** (вручную или `next-pwa`) | Иконка «как приложение» на телефоне родителя |

## Почему LiveKit (а не другое)

| Вариант | Плюсы | Минусы | Вердикт |
|---|---|---|---|
| **LiveKit Cloud** | Open-source, щедрый free-tier, отличные React-компоненты, простой токен-модель, можно self-host позже | Нужен свой эндпоинт токенов | ✅ Выбран |
| Daily.co | Очень простой prebuilt-iframe, быстрый старт | Проприетарный, free-tier скромнее | Хорошая альтернатива |
| Jitsi (self-host) | Полностью бесплатно, можно встроить iframe | Нужен и обслуживается свой сервер, NAT/TURN на себе | Если хочется $0 без облака |
| Свой WebRTC | Максимум контроля и обучения | Недели работы, TURN-серверы, отладка | Только если цель — учиться |

Daily.co — реальный запасной план: если LiveKit покажется сложным, переключиться
несложно, архитектура (фронт + эндпоинт токенов + облако) та же.

## Примерный список зависимостей

```bash
# каркас проекта
npx create-next-app@latest video-rings --typescript --tailwind --app

# LiveKit
npm install livekit-client @livekit/components-react @livekit/components-styles
npm install livekit-server-sdk   # для /api/token (только сервер)
```

`.env.local` (НЕ коммитить — секреты):

```env
LIVEKIT_API_KEY=...           # из LiveKit Cloud
LIVEKIT_API_SECRET=...        # из LiveKit Cloud
LIVEKIT_URL=wss://<проект>.livekit.cloud
FAMILY_CODE=...               # любой длинный секрет для привязки устройств
```

## Оценка нагрузки и бесплатных лимитов

Семья = пара звонков в день, один поток в каждую сторону, 1-на-1. Это
**мизерный** трафик по меркам любого сервиса:

- LiveKit Cloud free-tier (на момент планирования) даёт тысячи бесплатных
  участнико-минут в месяц и достаточный объём трафика — для семьи с огромным
  запасом. **Проверить актуальные лимиты на livekit.io/pricing перед стартом.**
- Vercel free-tier: статика + serverless-функция токенов — на семейный масштаб
  бесплатно с запасом.

Вывод: на старте и в обозримом будущем — **$0**. Платный план понадобится только
если проект вырастет далеко за рамки семьи.

## Требования к окружению разработки

- Node.js LTS (актуальная версия).
- Любой современный браузер для теста (для камеры на dev — `localhost` работает
  без HTTPS, это исключение браузера).
- Для теста «двух сторон» удобно: одно окно обычное + одно инкогнито, либо
  телефон + компьютер.
