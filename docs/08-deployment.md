# 08 — Деплой и хостинг

Цель: сайт доступен в интернете по HTTPS (иначе камера не работает) и
устанавливается на телефон родителя как приложение (PWA).

## Почему Vercel

- Бесплатный тариф, которого для семьи хватает с запасом.
- **Авто-HTTPS** — критично: `getUserMedia` (камера/микрофон) требует HTTPS.
- Serverless-функции — наш `/api/token` (и позже `/api/ring`) работают без
  отдельного сервера.
- Нативная поддержка Next.js (тот же создатель).

Альтернативы: Netlify, Cloudflare Pages — тоже подойдут, схема та же.

## Шаг 1. Репозиторий

1. Залить проект на GitHub (приватный репозиторий — нормально).
2. Убедиться, что `.env.local` в `.gitignore` и секреты **не** попали в git.

## Шаг 2. Подключение к Vercel

1. Зайти на vercel.com через GitHub.
2. New Project → выбрать репозиторий → Vercel сам определит Next.js.
3. В **Environment Variables** добавить (значения — из LiveKit, см.
   [07-livekit-setup.md](07-livekit-setup.md)):

   | Переменная | Где используется |
   |---|---|
   | `LIVEKIT_API_KEY` | сервер (`/api/token`) |
   | `LIVEKIT_API_SECRET` | сервер (`/api/token`) |
   | `LIVEKIT_URL` | сервер |
   | `NEXT_PUBLIC_LIVEKIT_URL` | клиент (тот же `wss://`-URL) |
   | `FAMILY_CODE` | сервер (привязка устройств) |

4. Deploy. Через минуту получаем адрес вида `video-rings.vercel.app` с HTTPS.

## Шаг 3. Свой домен (по желанию)

Можно оставить бесплатный `*.vercel.app`. Для «солидности» и простоты запоминания
родителям — купить короткий домен (например, `nasha-svyaz.ru`) и привязать в
Vercel (Settings → Domains). HTTPS-сертификат Vercel выпустит автоматически.

Не обязательно для работы — чисто удобство.

## Шаг 4. PWA — иконка «как приложение»

Чтобы у родителя на телефоне появилась иконка и сайт открывался во весь экран
без адресной строки:

1. Добавить `manifest.json` (имя, иконки, `display: standalone`, фон/цвет).
2. Добавить иконки приложения (192px, 512px).
3. Подключить минимальный service worker (для установки PWA; позже он же
   пригодится для Web Push — см.
   [06-notifications-and-ringing.md](06-notifications-and-ringing.md)).
4. На телефоне: открыть сайт → «Добавить на главный экран».

В Next.js это делается вручную или через пакет `next-pwa`. На MVP можно отложить —
сайт работает и из обычного браузера; PWA относится к Фазе 2.

## Шаг 5. Настройка устройств родителей (делаю лично)

Один раз, на телефоне каждого родителя:

1. Открыть `https://<адрес>/setup?code=СЕМЕЙНЫЙ_КОД&name=mama`
   → код и имя сохранятся в браузере.
2. Добавить на главный экран (PWA-иконка).
3. Заранее дать разрешение на камеру и микрофон (сделать тестовый звонок).
4. Проверить реальный звонок со мной.

После этого родитель видит только иконку и кнопку «Позвонить».

## Шаг 6. Чеклист перед тем, как отдать родителям

- [ ] Сайт открывается по HTTPS.
- [ ] Звонок работает между двумя реальными устройствами в разных сетях
      (не только дома по одному Wi-Fi).
- [ ] Камера/микрофон запрашиваются и работают на телефоне родителя.
- [ ] Иконка PWA на месте, открывается во весь экран.
- [ ] Понятные сообщения при ошибках (нет сети, нет доступа к камере).
- [ ] Секреты только в переменных окружения Vercel, ничего нет в git.
- [ ] Семейный код задан и сохранён на устройствах.

## Обслуживание

- Обновления выкатываются автоматически при пуше в GitHub (Vercel пересобирает).
- Лимиты LiveKit и Vercel изредка проверять в их дашбордах — для семьи выход за
  бесплатные рамки крайне маловероятен.
- Раз в несколько месяцев — обновить зависимости (`npm update`) и сверить
  изменения в API LiveKit.
