# 📞 Video Rings — семейная видеосвязь

Простой и удобный сайт для видеозвонков внутри семьи: я и родители. Главная цель —
**максимальное удобство для нетехнических пользователей**: открыл сайт → нажал одну
большую кнопку → говоришь.

> Статус проекта: **MVP-каркас готов** (Фаза 1). Видеозвонок 1-на-1 работает;
> уведомлений пока нет — созваниваемся по договорённости. Планы — в `docs/`.

---

## TL;DR — что решили

| Вопрос | Решение |
|---|---|
| Видео-технология | Готовый облачный сервис **LiveKit Cloud** (бесплатный тариф) |
| Участники | Только **1-на-1** |
| Вход | **Одна большая кнопка «Позвонить»**, без логинов и паролей |
| Устройства | Разные: телефон, компьютер, планшет → адаптивный интерфейс |
| Стоимость старта | **$0** (бесплатные тарифы LiveKit + Vercel) |

Подробнее — в [docs/01-vision-and-decisions.md](docs/01-vision-and-decisions.md).

## 🎯 Главный принцип

> Любую фичу, которую родитель не сможет освоить за **30 секунд без объяснений**,
> мы либо упрощаем, либо прячем. Удобство важнее количества функций.

## 🚀 Запуск локально

```bash
# 1. зависимости (уже установлены, если папка node_modules на месте)
npm install

# 2. секреты: скопировать пример и заполнить ключами из LiveKit Cloud
copy .env.local.example .env.local      # PowerShell/Windows
#   укажи LIVEKIT_API_KEY, LIVEKIT_API_SECRET, NEXT_PUBLIC_LIVEKIT_URL, FAMILY_CODE

# 3. запуск дев-сервера
npm run dev                              # http://localhost:3000
```

> На `localhost` камера работает без HTTPS (исключение браузера). Для проверки
> «двух сторон»: обычное окно + окно инкогнито, или телефон + компьютер после
> деплоя на Vercel.

Где взять ключи LiveKit — [docs/07-livekit-setup.md](docs/07-livekit-setup.md).
Деплой на Vercel и настройка устройств родителей —
[docs/08-deployment.md](docs/08-deployment.md).
